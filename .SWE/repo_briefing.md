## Project Overview

- **Name:** `serendipity-webui` (version `0.1.0`)
- **Description (from pyproject.toml):** "Standalone web interface for the Serendipity AI agent platform"
- **License:** MIT (see `LICENSE`)
- **Primary language:** Python (>= 3.12) for the backend; vanilla JavaScript (ES Modules) + HTML/Jinja2 templates for the frontend.
- **Purpose:** A standalone web UI for managing the Serendipity AI agent platform: AI agents, conversations, workflows, LLM configuration, MCP servers, toolsets, skills, scheduled tasks, and settings. The web UI connects to a separately-deployed Serendipity backend server (not in this repo).
- **Note from README:** The Serendipity backend server has not been publicly released yet. This repository contains only the web UI frontend, which requires the backend to function.

### Tech Stack (as stated in README)

- **Backend:** FastAPI (Python)
- **Frontend:** Vanilla JavaScript (ES Modules), TailwindCSS
- **Templating:** Jinja2
- **Authentication:** Bitcoin WIF key signing (message signing)
- **Real-time:** WebSocket for streaming responses

## Architecture Summary

- **Single-module backend:** The entire FastAPI application lives in `app/main.py`. It defines one `FastAPI` instance (`app = FastAPI(title="Serendipity Web UI")`) and registers all routes via decorators.
- **Entry points:**
  - ASGI app object: `app.main:app` (used by uvicorn / Docker).
  - Script entrypoint: `app/main.py` has an `if __name__ == "__main__":` block (line 344), tested by `unittests/test_main_entrypoint.py`.
  - Container entrypoint: `entrypoint.sh` runs `uvicorn app.main:app --host 0.0.0.0 --port 8080`.
- **Routes (GET), from `app/main.py`:**
  - `/` -> `home`
  - `/agent/{agent_name}` -> `agent_home`
  - `/agent/{agent_name}/conversations` -> `conversations`
  - `/agent/{agent_name}/conversation` -> `conversation` (optional query `conversation_id`)
  - `/settings` -> `settings`
  - `/agent/{agent_name}/edit` -> `edit_agent`
  - `/mcps` -> `mcps`
  - `/toolsets` -> `toolsets`
  - `/skills` -> `skills`
  - `/llms` -> `llms`
  - `/scheduled-tasks` -> `scheduled_tasks`
  - `/agent/{agent_name}/workflows` -> `workflows` (optional queries `workflow_id`, `node_id`)
  - `/api/tts-proxy` -> `tts_proxy` (query params: `server`, `voice`, `text`, optional `style`, `language`, `speed`)
- **Server-side helpers in `app/main.py` (TTS-proxy SSRF validation):** `_get_allowed_tts_hosts`, `_resolve_host`, `_is_blocked_ip`, `_validate_tts_server`.
- **Templating & static assets:** Jinja2 templates rendered to `HTMLResponse`; `StaticFiles` mounted for static assets; `Jinja2Templates` used for rendering.
- **Frontend:** Vanilla JS modules (`api.js`, `bitcoin.js`) plus vendored libraries (mermaid, marked, dompurify, highlight.js, secp256k1, sha256, ripemd160). XSS handling uses DOMPurify (`purify.min.js`); tests assert sanitization in templates.
- **Auth model (per README):** All POST requests to the backend are authenticated with Bitcoin message signing; request format includes `message`, `signature`, `address`, and `data`.
- **Frontend/backend split:** This repo is frontend-only; it communicates with an external Serendipity backend (default `localhost:42069`, WebSocket port `8765`).

## How to Build/Run

### Local development (from README)

    # Create virtual environment
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate

    # Install dependencies
    pip install -r requirements.txt

    # Run the development server
    uvicorn app.main:app --reload --host 0.0.0.0 --port 8080

### Docker (recommended in README)

    # Build the image
    docker build -t serendipity-webui .

    # Run the container
    docker run -p 8080:8080 serendipity-webui

The app is served at `http://localhost:8080`.

**Dockerfile details:** multi-stage build.
- Stage 1 (`builder`): `python:3.12-slim`, creates venv at `/opt/venv`, installs `requirements.txt`.
- Stage 2 (`runtime`): `python:3.12-slim`, copies venv + `app/`, `static/`, `entrypoint.sh`; exposes port `8080`; runs as non-root user `appuser`; `ENTRYPOINT ["./entrypoint.sh"]`.
- `entrypoint.sh`: starts `uvicorn app.main:app --host 0.0.0.0 --port 8080` in background then `sleep infinity`.

### CSS build (`build-css.sh`)

    ./build-css.sh          # one-off minified build
    ./build-css.sh --watch  # watch mode

The script downloads the Tailwind CSS CLI binary if `./tailwindcss` is missing, then runs it against `static/css/tailwind.css` producing `static/css/tailwind.output.css`.

### Docker build/push helper (`build_docker.py`)

A CLI script (argparse) that builds and pushes a Docker image.

    python build_docker.py <docker-image-name> [--username USERNAME] [--tag TAG] [--latest]

- Default `--username` = `valyriantech`; default `--tag` = today's date (`%d%m%Y`).
- Runs `docker build` and `docker push`; with `--latest` also tags/pushes `:latest`.

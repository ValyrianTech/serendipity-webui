A standalone web interface for the Serendipity AI agent platform. Provides a UI for managing AI agents, conversations, workflows, LLM configurations, MCP servers, toolsets, skills, scheduled tasks, and system settings. The README notes the Serendipity backend server has not been publicly released; this repo contains only the web UI frontend and requires the backend to function.

Key capabilities (from README): Agent management, real-time chat via WebSocket streaming, workflows, voice support (recording/transcription/TTS playback), file handling, multi-provider LLM configuration (OpenAI, Anthropic, Groq, Ollama, vLLM, etc.), MCP server management, toolsets, dark/light mode, and Bitcoin (WIF key) authentication.

## Architecture Summary

- **Backend framework:** FastAPI (`app = FastAPI(title="Serendipity Web UI")`).
- **Entry points:**
  - ASGI app object: `app.main:app` (served by `uvicorn`).
  - Direct script execution: `app/main.py` has an `if __name__ == "__main__":` block that calls `uvicorn.run(app, host="0.0.0.0", port=8080)`.
  - Docker entrypoint: `entrypoint.sh` runs `uvicorn app.main:app --host 0.0.0.0 --port 8080` in the background, then `sleep infinity`.
- **Templating:** Jinja2 via `fastapi.templating.Jinja2Templates`, directory `app/templates`. Templates extend `base.html` using `{% block %}` sections.
- **Static assets:** Mounted at `/static` via `StaticFiles(directory=BASE_DIR / "static")` where `BASE_DIR` is the repo root (parent of `app/`).
- **Frontend:** Vanilla JavaScript ES modules (`static/js/api.js`, `static/js/bitcoin.js`), TailwindCSS (compiled to `tailwind.output.css`), and vendored libraries (marked, mermaid, DOMPurify, highlight.js, secp256k1, sha256, ripemd160).
- **Routes (from `app/main.py`):**
  - `GET /` -> `agents.html`
  - `GET /agent/{agent_name}` -> `agent_home.html`
  - `GET /agent/{agent_name}/conversations` -> `conversations.html`
  - `GET /agent/{agent_name}/conversation` (optional query `conversation_id`) -> `conversation.html`
  - `GET /agent/{agent_name}/edit` -> `edit_agent.html`
  - `GET /agent/{agent_name}/workflows` (optional query `workflow_id`, `node_id`) -> `workflows.html`
  - `GET /settings` -> `settings.html`
  - `GET /mcps` -> `mcps.html`
  - `GET /toolsets` -> `toolsets.html`
  - `GET /skills` -> `skills.html`
  - `GET /llms` -> `llms.html`
  - `GET /scheduled-tasks` -> `scheduled_tasks.html`
  - `GET /api/tts-proxy` -> proxies TTS synthesis requests to a configurable TTS server (query params: `server`, `voice`, `text`, `style`, `language`, `speed`); uses `httpx.AsyncClient` with a 300 s timeout and a `StreamingResponse`.
- **Authentication (client-side):** Bitcoin WIF key signing handled in `static/js/bitcoin.js`; settings/keys stored in browser `localStorage`.
